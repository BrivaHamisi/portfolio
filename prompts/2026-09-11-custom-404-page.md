# Custom 404 page

## Goal

There's currently no catch-all route, so an unmatched URL falls through to a blank/router-error state instead of a real page. Add a 404 view matching the Linear design system rather than a stock browser/router error.

## Files touched

- `src/views/NotFoundView.vue` — new.
- `src/router/index.js` — add a catch-all route (`path: '/:pathMatch(.*)*'`) rendering it.

## Approach

- Match existing page conventions: `bg-void min-h-screen`, `text-heading`/`text-heading-sm` headline, `text-fog` body copy, a single primary `acid-lime` button ("Back to Home") using the established primary-button pattern + `v-flashlight`.
- Keep copy short and on-brand, no illustration/asset needed.

## Verification

- `npm run serve`, visit a nonexistent path (e.g. `/does-not-exist`), confirm the new page renders instead of a blank screen.
- `npm run build` succeeds.
